# Grid Expectations website

Static pages for the Grid Expectations app (ZMRTN LLC), served by GitHub Pages at https://zachmartin88.github.io/gridexpectations/.

- `index.html`: landing page (screenshots in `img/` show only our own sample chart)
- `privacy.html`: privacy policy
- `support.html`: support and FAQ
- `terms.html`: terms of use (Apple standard EULA + subscription terms)

This repository holds only the website. The app source is not here.
